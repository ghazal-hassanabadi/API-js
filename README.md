# 🎬 CineFind

یک سایت ساده برای جستجوی فیلم. اسم فیلم را می‌نویسی و پوستر، امتیاز و سال ساخت آن را می‌بینی. این پروژه با `HTML`، `CSS` و `JavaScript` خالص ساخته شده و از `OMDb API` اطلاعات فیلم‌ها را می‌گیرد.

## 🔗 دمو
[https://ghazal-hassanabadi.github.io/API-js/]



## ✨ امکانات

- جستجوی فیلم با اسم
- نمایش پوستر، نام، امتیاز `IMDb` و سال ساخت
- نمایش پیام برای حالت‌های «در حال بارگذاری»، «فیلمی پیدا نشد» و «خطا»
- طراحی ریسپانسیو برای موبایل، تبلت و دسکتاپ
- تم تیره‌ی بنفش

## 🛠️ تکنولوژی‌ها

- `HTML5`
- `CSS3` (با متغیرها، `Grid` و `Flexbox`)
- `JavaScript`
- [OMDb API](https://www.omdbapi.com/)
- [Font Awesome](https://fontawesome.com/) برای آیکن‌ها

## 🌐 API از کجا آمده؟

اطلاعات فیلم‌ها از سایت [OMDb API](https://www.omdbapi.com/) گرفته می‌شود. این سرویس رایگان است و برای استفاده فقط یک کلید (`API Key`) لازم دارد.

**گرفتن کلید:** به سایت `omdbapi.com` برو، از بخش `API Key` ایمیلت را وارد کن و کلید رایگان را از ایمیل بگیر.

دو درخواست در پروژه استفاده شده:

- **جستجو با اسم** (`s=`): لیست فیلم‌ها را می‌دهد
- **جزئیات با شناسه** (`i=`): امتیاز و اطلاعات کامل هر فیلم را می‌دهد

## 🚀 اجرای پروژه

۱. پروژه را دانلود کن.

۲. کلید خودت را در فایل `js/index.js` بگذار:

```javascript
const API_KEY = "کلید-خودت-اینجا";
```

۳. فایل `index.html` را باز کن، یا با `Live Server` اجرایش کن.

## 🧯 اگر فیلم‌ها نمایش داده نشدند

- مطمئن شو کلید `API` را درست گذاشته‌ای و آن را از ایمیل فعال کرده‌ای.
- اتصال اینترنت را چک کن.
- اگر باز هم کار نکرد، فیلترشکن (`VPN`) را روشن کن.
- در نسخه‌ی رایگان، هر کلید روزی ۱۰۰۰ درخواست دارد. اگر تمام شود، خطا می‌دهد.



## 🧠 چیزهایی که یاد گرفتم

- گرفتن اطلاعات از `API` با `fetch` و `async/await`
- ساختن آدرس درخواست با `URLSearchParams`
- گرفتن چند درخواست هم‌زمان با `Promise.all`
- مدیریت خطا با `try / catch / finally`
- ساخت کارت‌ها با `createElement` و `template literal`
- طراحی ریسپانسیو با `Grid` و `media query`

## 🤖 استفاده از هوش مصنوعی

از هوش مصنوعی برای یادگیری مفاهیم، تحلیل کد و ساختار `JavaScript` کمک گرفتم.
